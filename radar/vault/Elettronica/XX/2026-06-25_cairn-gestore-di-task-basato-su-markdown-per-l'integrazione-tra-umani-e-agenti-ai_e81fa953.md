# Riassunto

Cairn è un sistema di gestione dei task che utilizza file Markdown all'interno di repository Git come unica fonte di verità, eliminando la necessità di database esterni. Lo strumento è progettato per permettere a agenti AI e sviluppatori umani di collaborare in modo sincronizzato tramite il protocollo MCP, facilitando il tracciamento del lavoro e la revisione del codice.
