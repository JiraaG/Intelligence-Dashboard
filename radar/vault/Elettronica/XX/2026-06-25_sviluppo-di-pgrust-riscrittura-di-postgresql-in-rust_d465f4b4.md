# Riassunto

Il progetto pgrust mira a riscrivere il database PostgreSQL 18.3 in linguaggio Rust per migliorare la manutenibilità e l'integrazione con l'IA. Il sistema ha superato oltre 46.000 test di regressione, garantendo la compatibilità dei dati a livello di disco, pur non essendo ancora pronto per la produzione.
