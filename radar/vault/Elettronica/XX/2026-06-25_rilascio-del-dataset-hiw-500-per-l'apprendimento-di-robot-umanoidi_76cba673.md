# Riassunto

BitRobot, Unitree e Hugging Face hanno rilasciato HIW-500, un dataset di oltre 500 ore di teleoperazione di robot umanoidi Unitree G1 in ambienti domestici reali nel Sud-est asiatico. Il dataset mira a migliorare l'esecuzione di task domestici complessi attraverso l'integrazione di dati visivi, stati del robot e annotazioni linguistiche.
