# Riassunto

Dial9 è un tool di monitoraggio per applicazioni Rust e il runtime Tokio, progettato per registrare eventi di sistema e CPU per diagnosticare problemi di performance p99+. Lo strumento permette l'esportazione di tracce per l'analisi tramite sito statico HTML o agenti automatizzati, facilitando il debugging in ambienti di produzione.
