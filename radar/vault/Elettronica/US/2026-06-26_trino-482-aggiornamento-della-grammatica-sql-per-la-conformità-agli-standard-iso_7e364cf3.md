# Riassunto

Il motore di query Trino ha rilasciato la versione 482, introducendo significativi miglioramenti alla grammatica SQL per allinearsi allo standard ISO 9075. L'aggiornamento implementa nuove funzionalità come l'operatore BETWEEN SYMMETRIC, la logica a tre valori esplicita e nuovi predicati per le sottoquery, ottimizzando l'analisi dei dati complessi.
