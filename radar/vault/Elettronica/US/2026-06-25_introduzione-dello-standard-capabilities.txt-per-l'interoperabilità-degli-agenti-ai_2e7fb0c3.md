# Riassunto

Viene proposto lo standard capabilities.txt, un file di configurazione aperto che permette agli agenti AI di scoprire autonomamente le funzionalità operative di un host web, superando le integrazioni proprietarie. Questo protocollo funge da livello di scoperta prima dell'invocazione di API o server MCP, facilitando l'automazione di servizi in settori come e-commerce, finanza e sanità.
